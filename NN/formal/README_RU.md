# Статус формальной проверки

Lean-файл перенесён из последней доступной версии исходного обсуждения без изменения формул. Пользователь сообщил об успешной проверке полного файла после исправлений. Это подтверждение со стороны пользователя, а не новый запуск Lean здесь. Lean/Mathlib в текущем окружении отсутствуют.

Комментарий в самом .lean оставлен как историческое описание первоначальной среды автора. Чтобы зафиксировать воспроизводимость, в своём отдельном Lean-проекте сохраните lean-toolchain и lake-manifest.json, затем выполните:

```bat
lake env lean PGR_Neural_Verification.lean
```

Копирование файла в папку Python-комплекта не подключает Mathlib. Здесь библиотека не устанавливается и Lean не запускается.

Проверяется математика отдельных операций над вещественными числами и абстрактное условие разрешения. Не доказаны свойства обученной модели, argmax, float32, C++ или безопасность реального WinAPI. Подробности: docs/MATHEMATICAL_MODEL_RU.md.
