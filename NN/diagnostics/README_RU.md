# Прежняя диагностика внутри NN

Полностью сохранены правила v1/v2, их 12 Python-тестов, 50 Windows-записей
и 54 проекта. Внешних зависимостей от прежних папок нет.

Из NN:

```bat
python diagnostics\test_all.py -v
python diagnostics\evaluate.py
python diagnostics\run_suite.py
```

Правила — ориентир сравнения, не нейросеть. Эта папка не читает BD и не
обучает модель. Собранные здесь случаи имеют статус регрессионных, а не
независимой базы обучения. Исторические документы в docs сохранены для
происхождения; актуальный план и структура NN/BD — в корневом NN/docs.
