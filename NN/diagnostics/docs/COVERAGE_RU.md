# Матрица покрытия и границы

| Сценарий | Обработка сейчас | Как проверяется |
|---|---|---|
| Отсутствующий заголовок с расширением/без/с пробелами | header_missing при связанном фрагменте include | Реальные GCC/MinGW-данные, проекты, граничные проверки |
| Отсутствующий входной файл, в том числе .hpp | unknown, если нет связанного include | Проект и отрицательные тесты |
| Пропущенные скобки, разделители, конец конструкции | Конкретные ожидаемые delimiter-шаблоны syntax_error | Реальные сообщения и проекты |
| Необъявленная переменная, функция, namespace | undeclared_identifier по двум явным формулировкам | Проекты, шаблон с суффиксом GCC16 |
| Явное преобразование типов, ссылка, narrowing | type_mismatch по ограниченным шаблонам | Проекты и тесты |
| Неоднозначная перегрузка, no matching function | unknown: нельзя вывести только из этих слов несовместимость типов | Проект неоднозначности, документация |
| Нет определения символа, C/C++ linkage, шаблон/vtable | undefined_reference при сообщении компоновщика | Проекты |
| Дубли определений в разных единицах | multiple_definition при компоновке | Проекты |
| Повторное определение в одной единице | unknown | Проекты |
| Неизвестная опция GCC | unknown_option | Проекты |
| Известная опция, неверное значение | unknown | Проект -fmax-errors=banana |
| Не найдена библиотека как файл | unknown | Проекты |
| #error, static_assert, private/protected, deleted, неполный тип, poison | unknown | Проекты и отрицательные тесты |
| Слова известных ошибок внутри #error/static_assert | unknown, без поиска по всему тексту | Проекты и тесты |
| Предупреждение и note | unknown; не классифицируются как ошибка | Проект успешной сборки с warning и тесты |
| CMake/Make/Ninja/MSBuild/MSVC | unknown; поддержка инструментов не заявляется | Синтетические строки отказа, без реальных сборок |
| Ошибки памяти устройства/релокаций ARM, формата объекта | unknown | Синтетические строки, не реальные ARM-прогоны |
| Нет доступа, выходной файл занят, закончился диск/RAM | unknown; причина не лечится автоматически | Несколько синтетических диагностик; ситуации ОС не воспроизводились |
| Русский/другой язык сообщения | unknown по неподходящим формулировкам | Отрицательный тест; гарантии всех языков нет |
| Неверный JSON, дубли id, пустой набор | Ошибка ввода, код 2 | Автоматические проверки |
| Отсутствующий компилятор | Код 2 с объяснением | Автоматическая проверка |
| Тайм-аут/ошибка запуска | Сохранение статуса и исключение из оценки | Реализованы обработчики; тестируется пропуск записи timeout, не зависание всего дерева ОС |
| Занятая папка отчёта | Отказ без перезаписи | Автоматическая проверка |
| Прерывание скрипта/нет места для отчёта | Возможен частичный результат; JSONL сбора сбрасывается после случая | Зафиксированное ограничение; исчерпание диска не моделировалось |
| Длинный/многострочный/неоднозначный диагностический вход | unknown | Граничные тесты |
| Полностью неизвестная формулировка | Обычно unknown; универсальной гарантии нет | Открытое множество; будущий независимый набор обязателен |

Все совпадения относятся к фиксированным правилам. Нейросетевая модель пока не обучена. После финального Windows-прогона этап фиксируется; новые ошибки добавляются по потребности, а не как бесконечное обязательное условие начала нейросетевого прототипа.
