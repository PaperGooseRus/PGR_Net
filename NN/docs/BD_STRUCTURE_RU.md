# Соседняя BD — новая раскладка v2

BD теперь находится рядом с NN, без вложенного имени корпуса:

| Путь | Назначение |
|---|---|
| ../BD/bd.py | Единая точка запуска генератора и обработки |
| ../BD/tools/ | Исполняемые скрипты |
| ../BD/projects/ | C/C++/CMake-проекты |
| ../BD/catalog/ | Каталог и таксономия |
| ../BD/splits/ | train/val/test |
| ../BD/repairs/ | Парные патчи |
| ../BD/observations/<compiler>/ | Исходные наблюдения |
| ../BD/datasets/<compiler>/ | Подготовленные train.jsonl/val.jsonl/test.jsonl |
| ../BD/reports/ | Отчёты сборок, текущего аудита и истории |
| ../BD/manifests/ | Хеши поставки и история перемещения |

Из NN: `python data_tools\inspect_bd.py --bd "..\BD"`.
Из BD: `python bd.py info`, `python bd.py check`, `python bd.py audit`.
Полная инструкция — ../BD/README_RU.md. Старый v1-контракт и старые пути
по-прежнему поддержаны адаптером для обратной совместимости.

Это обновление только маршрутов чтения: математика/градиенты NN не менялись.
В исходном архиве GCC содержит 28 match=false; текущий адаптер дополнительно
показывает rows_with_failed_observation в ранее подготовленных выборках.
Не считать полный training автоматически очищенным от проблем наблюдений.
Распределение по парам не даёт независимости шаблонов; target.build_ok корпуса
включает runtime outcome. 116 категорий+CLEAN не становятся семью классами NN.
