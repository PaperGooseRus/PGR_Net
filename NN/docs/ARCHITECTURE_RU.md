# Архитектура NN 0.4.0

Математическая часть сохранена: среднее представлений токенов, compiler/stage
one-hot, первый affine, ReLU, второй affine и softmax. Новая версия меняет
жизненный цикл параметров: они теперь переживают завершение процесса.

| Модуль | Зависит от | Обязанности |
|---|---|---|
| math | C++17 | Matrix, affine, ReLU, softmax, проверки конечности |
| model | math | Shape, Parameters, Network, ручной пример |
| training | model | Loss/backward, инициализация, SGD, mini-batch цикл |
| storage | model | Формат PGRNN v1, байтовая сериализация, файловый транспорт |
| demo | model/training/storage по назначению | CLI и отчёты опыта |
| tests | проверяемые модули | Численные, файловые и процессные проверки |

storage не зависит от training. Программа только для inference может
линковать PGR::neural_storage без SGD. Network не знает о файлах/CLI и остаётся
неизменяемой после создания. Чистые функции backward и sgd_step не получили
скрытого сохранения или чтения данных. Никаких процессов внутри forward нет.

Формат и разбор сосредоточены в storage/src/model_io.cpp. Файловая публикация
без перезаписи — в storage/src/file_io.cpp с отдельными Windows/POSIX ветками.
Сырые C++-структуры не записываются. После load создаётся новая Network с
проверенными размерами и конечными числами; рабочую сеть можно заменить только
после успешного возврата функции. Полный контракт — MODEL_FORMAT_RU.md.

CMake-цели PGR::neural_math, PGR::neural_model, PGR::neural_training и
PGR::neural_storage самостоятельны относительно GUI и PGR_Make. У каждого
каталога модульный CMakeLists.txt. build_and_test.py использует те же исходники
через g++ без CMake и компилирует каждый общий объект один раз.

training_demo управляет параметрами маленького опыта, сохраняет model.pgrnn,
проверяет его загрузкой, затем пишет CSV/JSON. model_demo загружает веса в новом
процессе, вызывает forward с явными индексами и печатает JSON. Он не вызывает
инициализацию или обучение. --copy-to опционален и использует тот же save_model_new.

Один поток вычислений, без -ffast-math. Потоки Python используются только
регрессионным тестом конкурентных файловых записей. Лимиты Shape/Matrix,
батча и числа обновлений сохранены; формат дополнительно ограничен 64 MiB
и расчётом реальной длины до выделения весов. Это не квоты всей RAM/CPU ОС.
Нет SIMD/BLAS/GPU/квантования или автоматического выполнения исправлений.
