# Функция потерь и обратное распространение 0.2.0

## Прямой проход сохранён

    m = (1/n) sum_i E[token_i], n>0
    x = concat(m, compiler_one_hot, stage_one_hot)
    a = W1*x+b1
    h = ReLU(a)
    z = W2*h+b2
    p = softmax(z)

## Устойчивая кросс-энтропия

Для целевой категории y, u=max(z):

    L = log(sum_k exp(z_k-u)) + (u-z_y)

Не вычисляем -log(p_y) по машинной вероятности: p_y может округлиться до
нуля. Например z=[1000,-1000], y=1 даёт конечную L=2000. Переполнение иных
промежуточных double приводит к исключению. Это не обещание вычислимости
для любых конечных double, в том числе +/-max_double.

## Аналитические производные

    delta = p-one_hot(y)
    dW2[k,j] = delta[k]*h[j]
    db2 = delta
    dh = transpose(W2)*delta
    da[j] = dh[j] при a[j]>0; иначе 0
    dW1[j,i] = da[j]*x[i]
    db1 = da
    dx = transpose(W1)*da
    dE[token_i,d] += dx[d]/n

Токен может повториться, его вклады суммируются в одной строке E. Неиспользуемые
строки имеют нулевой градиент. One-hot индексы дискретны, по ним не проводится
обучение; градиент первых d компонентов x распространяется в E.

ReLU в нуле не имеет обычной производной. В коде явно задан выбор da=0 для
этой точки. Это конвенция субградиента, не доказанная дифференцируемость.

Для батча B: средние L и grad — суммы по примерам, делённые на B. Пустой батч
запрещён. Лимит 256 — защитное ограничение примера, не размер обязательного
будущего обучающего набора. Оптимизатора и обновления параметров пока нет.

## Проверки

Ручной пример с z=[2,0], y=0:

    L ≈ 0.1269280110429725
    db2 ≈ [-0.1192029220221176, 0.1192029220221176]
    dW2[0,0] ≈ -0.2384058440442352
    dE[1,0] = dE[2,0] ≈ -0.0596014610110588

В тестах каждый из 26 скалярных параметров сравнивается с:

    dL/dtheta_j ≈ (L(theta+eps*e_j)-L(theta-eps*e_j))/(2*eps)
    eps=1e-6

Пять сценариев: один пример, другая цель/контекст, повторяющиеся токены,
две активные ReLU, батч. Это 130 сравнений скалярных производных. Проверяем,
что +/-eps не пересекли излом ReLU. Критерий: abs_error <= 2e-7 +
2e-5*abs(numerical). Печатается наибольшая абсолютная разница каждого сценария.
Отдельные проверки покрывают ноль ReLU, K=1/7/117, неверные цели, NaN/Inf,
пустой батч и неизменность параметров после backward.

Успех конечных разностей — численная проверка в выбранных точках, не общее
доказательство формулы. Приложенный Lean-файл не изменён и НЕ содержит
доказательств кросс-энтропии, градиентов, батча или соответствия C++ коду.
