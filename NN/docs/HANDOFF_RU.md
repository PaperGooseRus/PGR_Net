# NN 0.4.0 — состояние для продолжения

Реализованы CPU-forward, устойчивая cross-entropy, backward и средний батч,
проверки градиентов, seeded initialization, SGD и учебный цикл. Добавлены
PGRNN v1, точное хранение Shape/параметров, проверка формата/CRC/размеров/NaN/Inf,
сохранение под новым именем и загрузка в отдельном процессе.

Проверки: 15 forward + 13 gradients + 10 training + 27 storage = 65 C++.
16 прежних Python-тестов и 11 новых процессных = 27 Python. Новые процессные
запускаются автоматически build_and_test.py, а не test_all.py.
Пользователь подтвердил NN 0.3.0 на Windows 28.10.2026: 38 C++ и 16 Python,
учебный loss .7696972732 → .0045391035 за 160 обновлений. Новый этап 0.4.0
проверен на Linux GCC13.3; нативный Windows/MinGW и CMake здесь не запускались.

Все обучающие примеры до сих пор явно игрушечные: восемь последовательностей
индексов, K=2, фиксированный контекст. BD при обучении не читается. Точность=1
не является независимой оценкой. 117 кодов BD нельзя молча заменить двумя
классами toy или семью классами прежних правил.

.pgrnn содержит только Shape/параметры и architecture ID. Он не задаёт
токенизатор/классы/названия контекстов. Seed и настройки опыта находятся в
run.json; точное продолжение прерванного train_sgd не реализовано. Нельзя
выдавать файл для inference за полный checkpoint. CRC — не подпись и не
доказательство качества сети. Прежний Lean доказывает прежние абстрактные
свойства, а не double, C++ IO, backward, SGD или работу приложения.

Следующий этап: контракт задачи по BD, очистка наблюдений, train-only словарь,
токенизация и привязка семантики индексов к весам, затем обучение/оценка.
Идентификаторы/label/target/patch/split не должны попадать во вход сети.
Данные runner_error Windows и очистка временных каталогов BD — отдельная
задача генератора/сборщика; здесь их не переименовывать в ошибки компилятора.

NN самостоятельна, BD соседняя. Нет PGR_Make/Qt, свободного чата, GPU,
исполнения исправлений или агентных WinAPI-действий. Windows API нового
storage используется только для обычного чтения/сохранения выбранного файла.
