# Проверка NN 0.4.0 — 28.10.2026

Среда: Linux, GCC13.3, Python3.12. Сборка C++17 через g++, флаги
-O2 -Wall -Wextra -Wpedantic -Werror, без -ffast-math.

| Группа | Пройдено |
|---|---:|
| Forward | 15/15 |
| Cross-entropy и gradients | 13/13 |
| Инициализация, SGD, учебный цикл | 10/10 |
| Формат/IO моделей, C++ | 27/27 |
| Прежняя диагностика и контракт BD, Python | 16/16 |
| CLI, отдельные процессы и независимый разбор, Python | 11/11 |

Новые проверки включают сравнение с независимым файлом, созданным Python
struct/zlib, точное совпадение весов/всех forward traces и обученных прогнозов,
перенос -0.0/subnormal/крайних finite double, K=1/7/117. Все 340 вариантов
обрезания ручного эталона (длины 0..339), хвост, версии, тип/architecture/flags/
reserved, нулевые/гигантские размеры, произведение матриц и противоречивые
длины отклоняются. CRC проверяется для payload, заголовка и поля CRC.
NaN/Inf проверены во всех пяти массивах с правильно пересчитанным CRC.

Файловые проверки: новый файл, занятая цель/каталог, отсутствующий родитель,
отсутствующая/неправильная модель, файл >64 MiB до выделения буфера,
кириллица/пробелы, отсутствие служебных файлов после обычных отказов.
Восемь конкурирующих отдельных процессов дают ровно одного победителя
при сохранении в одно имя; исходные файлы сохраняются. Новый процесс inference
совпадает с контрольным входом в run.json, а Python независимо читает
little-endian числа и сверяет CRC с zlib. Повтор обучения даёт побайтно
одинаковые веса/CSV/JSON в той же сборке.

27 storage-тестов дополнительно прошли AddressSanitizer и UndefinedBehaviorSanitizer.
LeakSanitizer отключён (ASAN_OPTIONS=detect_leaks=0) из-за ограничений /proc
среды; проверка утечек не заявляется.

Учебный опыт не изменился: seed=20261028, epochs=80, batch=4, eta=.15,
8 примеров, 160 обновлений; loss .769697273227954 → .00453910351978503,
training_accuracy=1. Файл имеет 110 параметров, 1012 байт. Это не обучение
на диагностическом корпусе и не независимая тестовая оценка.

Пользователь подтвердил предыдущую NN 0.3.0 на Windows (38 C++/16 Python).
Нативная Windows-ветка новой 0.4.0 и CMake/CTest в этой среде не запускались.
В частности, Linux-тесты не доказывают семантику Windows API и отсутствие
антивирусных блокировок. Нет заявления о покрытии всех ошибок ОС/железа.
Полный Windows-прогон — те же две команды из README.

Полная поставка распакована отдельно в путь с кириллицей и пробелами.
Сверены 196 SHA-256 записей, повторены test_all.py и build_and_test.py
при PYTHONIOENCODING=cp1252: все группы прошли. Все пути из архива NN 0.3.0
присутствуют в новом комплекте. В ZIP только NN/, без результатов опытов,
временных файлов и зависимости от предыдущих отдельных комплектов.
