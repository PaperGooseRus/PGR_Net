# Замена старого BD

1. Сохрани отдельно собственные изменения, свежие логи и уникальные проекты.
2. Если папка BD уже существует, переименуй её в BD_old перед распаковкой:
   простое наложение оставит старые labels/training/scripts и вернёт путаницу.
3. Распакуй этот архив в родительскую PGR_Net: появится новая BD и обновятся
   только data_tools/inspect_bd.py, docs/BD_STRUCTURE_RU.md и SHA256SUMS.txt в NN.
4. Из BD выполни info/check/test/audit. Из NN — inspect_bd.py --bd ..\BD.
5. Сравни собственные дополнения с новой папкой и перенеси нужное; затем
   BD_old можно удалить вручную. NN с C++ и диагностикой удалять не нужно.

В новой BD нет дополнительного уровня PGR_Neural_Synthetic_Corpus_v1:
projects/catalog/splits находятся непосредственно внутри BD. Генератор
не переписывал проекты, разметку, наблюдения и готовые выборки: тест
source_data_preserved проверяет их исходные SHA256 из загруженного архива.

Прежние docs/SHA256 оставлены в docs/source_v1 как исторический источник;
активный манифест — manifests/SHA256SUMS.txt. Новые текущие отчёты аудитора
не подтверждают историческое заявление 0 ошибок: исходный GCC имеет 28
несовпадений. Это не результат перемещения каталогов.
