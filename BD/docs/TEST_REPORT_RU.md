# Проверка структурированного BD v2

Проверено на Linux Python 3.12/GCC 13.3:

- Все неизменяемые исходники, метки, разбиения, наблюдения и готовые выборки
  совпали по SHA256 с загруженным архивом после перемещения.
- Каталог: 7424 проекта, 3712 пары, 116 дефектных семейств. Разбиения
  5568/928/928. Структурный аудит пройден.
- Четыре проверки tools/test_layout.py прошли: новая раскладка, сохранность
  данных, генерация 232 проектов и 116 патчей во временной папке, справка CLI.
- Подготовка GCC-выборок в временной копии: 7396 записей, 28 неуспешных
  наблюдений исключены. Поставленные выборки не перезаписывались.
- Четыре прямых случая через перенесённый verify.one: compile_error,
  link_error, runtime_error и success подтверждены GCC. Весь корпус не
  перекомпилировался; CMake/Clang/Windows здесь не запускались.
- Обновлённый адаптер NN прочитал новый BD и исходный v1 ZIP.
- Хеши и команды повторно проверены на чистой распаковке архива.

28 GCC-несовпадений присутствовали в источнике до миграции; они сохранены.
Причины всех несовпадений в рамках структурирования не исправлялись.
